This directory contains key application screenshots demonstrating UI dashboard components, API endpoints, Docker container execution, and responsive views:

- `prediction.png`: Prediction result card with gauge meter, probability bar, and Recharts breakdown.
- `high-risk.png`: High risk churn prediction badge and critical zone indicator.
- `low-risk.png`: Low risk customer retention view with green safe zone indicators.
- `swagger.png`: FastAPI Swagger UI (`/docs`) with interactive endpoints.
- `docker.png`: Single-command Docker Compose orchestration (`docker compose up --build`).
- `mobile.png`: Responsive mobile view.
